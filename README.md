# 🎓 E-Learning Portal

A simple and user-friendly E-Learning Portal developed using PHP and MySQL. This project provides an online platform where students can access courses and learning materials.

## 📌 Project Overview

The E-Learning Portal is a web-based application designed to make online learning easier. It includes separate access for administrators and students, with features for managing courses and lessons.

## ✨ Features

- **User Registration:** New students can create an account.
- **User Login:** Secure login interface for accessing the portal.
- **Admin Dashboard:** Admin can manage courses, lessons, and students.
- **Course Management:** Add, view, and manage available courses.
- **Lesson Management:** Organize learning lessons for students.
- **Student Dashboard:** Students can access available courses and lessons.
- **Profile Support:** Supports user profile management.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Database Tool:** phpMyAdmin

## ⚙️ Installation and Setup

1. Install XAMPP on your computer.
2. Copy the project folder into the XAMPP `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin and create a database named `elearning_portal`.
5. Import the `database.sql` file into the database.
6. Configure your local database connection in `includes/db.php`.
7. Open the project in your browser using your local server URL.
